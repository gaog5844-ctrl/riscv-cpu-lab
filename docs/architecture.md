# 处理器结构

## 流水线

~~~text
取指后端 ↔ IF → ID → EX → MEM → WB → 提交记录
                    ↑    ↓
                 前递选择  D-cache ↔ 数据后端 / MMIO
IF ← 64 项 BHT/BTB ← EX 分支结果
~~~

顶层 `rv32_system` 连接核心和数据缓存。`cache_enable`、`predictor_enable` 在复位时设置，运行中保持不变；`ENABLE_SIMD` 是构建参数。

|阶段|处理什么|等待/冲刷|
|---|---|---|
|IF|请求、PC、预测下一 PC；最多一笔在途取指|旧路径响应被接收但丢弃|
|ID|译码、读寄存器、立即数；WB→ID 旁路|load-use 插入气泡|
|EX|ALU、分支、地址、乘法、迭代除法、SIMD|等待 MEM；误预测冲刷前端|
|MEM|单笔访存或 FENCE，保持请求直到完成|等待向前传播，避免重复请求|
|WB|更新寄存器并输出一次提交|异常到达后停机|

MEM→EX 前递优先于 WB→EX，同一寄存器有多个待写结果时，选择程序顺序中最近的一个。EX 阻塞期间会保存已前递的值。除法器只在启动沿锁存操作数，因此相关 load 尚未返回时，除法器也要继续等待。

乘法在 EX 中组合计算；除法使用 32 步恢复除法，除零和溢出按指令规定返回结果。处理器单发射，实际 CPI 受取指、分支、缓存和长运算影响。

## 缓存和预测

缓存地址：低 2 位为字节，4:2 为行内字，8:5 为组号，31:9 为标签。先选无效路，再选 LRU；脏行逐字写回，再逐字填充。一次只处理一个 CPU 访问，后端没有 burst。

SB/SH/SW 用四位字节使能合并。仅 0x80000000–0x800FFFFF 可缓存，MMIO 和越界访问走旁路。FENCE 会等待访存完成并写回所有脏行，已有有效行继续保留。

预测表索引 PC[7:2]，完整高位标签 PC[31:8]；两位饱和计数器控制条件跳转预测，BTB 保存目标。标签别名和间接跳转目标变化都可能造成误预测，由流水线冲刷处理。分支或跳转指令通过 EX，且未发生异常时，更新预测表。

## 总线接口

- valid/ready 同时为 1 的时钟沿接受请求，每通道最多一笔在途事务。
- 响应最早出现在接受请求的下一周期，不允许零延迟组合返回。
- 响应被反压时保持 valid、数据、错误状态。
- D 侧地址按 4 字节对齐；wstrb=0 为读，非零为带字节使能的写。
- I/D 是独立接口，共用仿真 RAM，不模拟共享总线仲裁。
- 未握手的取指可因跳转/异常撤销；已握手的旧路径取指仍须返回，再由核心丢弃。
- 不支持自修改代码、I/D 一致性或 FENCE.I。

## 内存和异常

|地址|含义|
|---|---|
|0x80000000–0x800FFFFF|1 MiB RAM；复位 PC=0x80000000|
|0x10000000|仿真字符输出，写最低字节|
|0x10000004|仿真 GPIO，读 0、写忽略；统计写次数检查错误路径|
|其他|访问错误|

仿真启动时先清零 RAM，再加载裸二进制；本实现的寄存器在复位时清零。程序直接运行，不经过操作系统或动态加载器，也未链接标准库。

发生异常时，该指令不写 rd、不提交正常 store，程序顺序中后面的指令被取消。核心输出出错指令的 PC、cause 和 tval 后停机。异常指令之前的提交予以保留；当前没有 mtvec/mepc/mcause CSR，也没有异常返回流程。

|cause|本工程含义|tval|
|---:|---|---|
|0|执行的跳转目标未按 4 字节对齐|目标地址，JALR 已清 bit 0|
|1|取指错误|取指地址|
|2|非法/不支持编码|原始指令|
|3|EBREAK|0|
|4 / 6|加载 / 存储未对齐|有效地址|
|5 / 7|加载 / 存储访问错误|当前访存有效地址|
|7|FENCE 写回失败，工程扩展约定|失败后端字地址|
|8|ECALL，工程用户程序约定|0|

表中的 ECALL 行为是本执行环境的约定，处理器没有完整的 U/M 特权级状态。脏行写回失败可能涉及先前已提交的 store，后端已经写入的字不会回滚，当前不支持完整的总线错误恢复。

支持 37 条基础计算、控制和访存指令，8 条 M 指令，以及 FENCE、ECALL、EBREAK。CSR、压缩、浮点、原子和标准 V/P 指令尚未实现，未支持的编码触发非法指令异常。系统也没有中断、MMU、操作系统或板级外设。测试范围见 [测试说明](verification.md)。
